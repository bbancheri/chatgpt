# Documents

Ce dossier rassemble les documents communs à plusieurs projets : études, spécifications, procédures et guides.

## Utilisation

- Choisir un nom qui indique le sujet et la nature du document.
- Préciser son objectif, son périmètre, son statut et ses sources lorsque ces éléments sont utiles.
- Conserver la version modifiable ; ajouter un export PDF si nécessaire pour la lecture ou le partage.
- Placer les documents propres à un seul projet dans le sous-dossier correspondant de [projets/](../projets/).

Les projets peuvent référencer les documents communs par des liens relatifs.
