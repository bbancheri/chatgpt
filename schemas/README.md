# Schémas

Ce dossier rassemble les schémas d’architecture et les représentations communes à plusieurs projets.

## Utilisation

- Conserver la source modifiable, par exemple un fichier `.drawio` ou `.mmd`.
- Ajouter, si utile, un export SVG, PNG ou PDF portant le même nom de base.
- Donner un titre au schéma et expliciter sa légende, son périmètre et ses principales hypothèses.
- Placer les schémas propres à un seul projet dans le sous-dossier correspondant de [projets/](../projets/).

Exemple de nom : `architecture-reseau.drawio` et son export `architecture-reseau.pdf`.
