# Scripts

Ce dossier rassemble les scripts et automatisations réutilisables entre plusieurs projets.

## Utilisation

Accompagner chaque script, ou ensemble de scripts, des informations nécessaires à son utilisation :

- Objectif et résultat attendu.
- Environnement et dépendances nécessaires.
- Paramètres, fichiers d’entrée et fichiers produits.
- Exemple d’utilisation et effets sur les systèmes ou les données concernés.
- Vérifications réalisées et limites connues.

Créer un sous-dossier lorsqu’un outil comporte plusieurs fichiers. Placer les scripts propres à un seul projet dans le sous-dossier correspondant de [projets/](../projets/).
